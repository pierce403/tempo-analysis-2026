Protocol/source invariant
-------------------------
- Tempo KeyAuthorization limits None = unlimited; Some([]) = deny all.
- allowed_calls None = unrestricted; Some([]) = deny all calls.
- wallet-cli store normalization maps a missing limits field to [].
- current output hardcodes unlimited false and shows 0.000000 when no first limit exists.

Impact demonstrated
-------------------
The released output represents the strongest protocol spend state as non-unlimited with no listed
limit. It also renders missing/unrestricted call scopes as an empty list. A responder relying on
this output can materially underestimate a stolen key's authority.

Important fix limitation
------------------------
The one-line proof is not a correct final fix: normalization has already collapsed protocol-
opposite missing and explicit-empty values. The implementation must preserve or query canonical
enforcement/scope modes.
