Impact demonstrated
-------------------

Current source shows that the matching tag selects both the code and workflow definition used by
official image/binary publication. Legitimate run history proves those configured paths operate.
Under the retained prerequisite—a compromised writer, GitHub App, deploy key, or release identity
that can create the tag—the public controls do not show an independent review gate requiring the
tagged commit to be approved main history.
