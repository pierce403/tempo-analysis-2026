Impact demonstrated
-------------------
A repository-controlled executable resolved after environment injection receives the complete
process environment and can preserve normal-looking tool output. If a same-repository PR can
control that workspace before a real credential-bearing step, the process boundary does not
protect the credential from PR code.

  findings require the stated same-repository member/writer path.
