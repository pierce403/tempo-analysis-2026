4. ORDINARY HTTPS ROOT RESPONSES

Exact collection command:

  awk -F '\t' 'NR>1 && ($2=="current_official_source_reference" || $2=="current_mpp_integration_source") {print $1"\t"$2}' recon/2026-08-21-source-referenced-hosts.tsv |
  while IFS=$'\t' read -r h c; do
    if ! dig +time=2 +tries=1 +short A "$h" | grep -q .; then
      printf '%s\t%s\tNO_DNS\n' "$h" "$c"
      continue
    fi
    data=$(curl --silent --show-error --connect-timeout 5 --max-time 12 \
      --proto '=https' --compressed -D - "https://$h/" 2>&1)
    rc=$?
    if [ "$rc" -ne 0 ]; then
      msg=$(printf '%s' "$data" | tail -1 | tr '\t\r\n' ' ')
      printf '%s\t%s\tCURL_ERROR=%s\n' "$h" "$c" "$msg"
      continue
    fi
    status=$(printf '%s' "$data" | awk '/^HTTP\// {gsub("\r",""); print $2; exit}')
    server=$(printf '%s' "$data" | awk 'BEGIN{IGNORECASE=1} /^server:/ {sub(/^[^:]*:[[:space:]]*/,""); gsub("\r",""); print; exit}')
    location=$(printf '%s' "$data" | awk 'BEGIN{IGNORECASE=1} /^location:/ {sub(/^[^:]*:[[:space:]]*/,""); gsub("\r",""); print; exit}')
    title=$(printf '%s' "$data" | perl -0777 -ne 'if (/<title[^>]*>\s*(.*?)\s*<\/title>/is) {$t=$1; $t=~s/<[^>]+>//g; $t=~s/[\r\n\t ]+/ /g; print substr($t,0,120)}')
    printf '%s\t%s\tstatus=%s\tserver=%s\tlocation=%s\ttitle=%s\n' \
      "$h" "$c" "${status:--}" "${server:--}" "${location:--}" "${title:--}"
  done

8. DEFENSIVE INTERPRETATION

Confirmed public trust entrypoints include the canonical site and developer
documentation, Tempo Auth, wallet, developer console, explorer, RPC, sponsor,
contract metadata, index/query APIs, snapshots, status, MPP/MCP, CLI artifact
host, and Rust docs. Several public test/dev/presto/Moderato endpoints also
remain routable. Their presence expands monitoring and ownership/lifecycle work;
it is not evidence of unauthorized access.

The public DNS control plane is delegated to Cloudflare. Web delivery is split
primarily between Cloudflare and Vercel, with Rust docs on GitHub Pages. Public
TXT records expose a sizeable identity, endpoint-management, communications,
and SaaS integration footprint. A financially motivated operator would likely
value those trusted identities and deployment accounts more than the shared
edge IPs themselves. Private tenant controls, user populations, privilege
assignment, SSO/MFA enforcement, recovery paths, logging, and account ownership
cannot be determined from these records.

Protective evidence includes rejecting DMARC for both the organizational domain
and subdomains, valid TLS certificates, and filtered 22/8545 on the five sampled
edge addresses. Follow-up owner-side validation should confirm DKIM alignment,
MTA-STS/TLS reporting intent, CAA policy intent, the necessity of every stale
verification record and nonproduction hostname, provider tenant ownership,
SSO/MFA/recovery controls, and that Cloudflare/Vercel origin restrictions prevent
direct-origin bypass. None of those private controls was tested here.
