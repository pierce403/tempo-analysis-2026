# Skills

Open the matching skill before repeating a documented procedure.

- `curator`: Read `skills/curator/SKILL.md` when a completed task teaches a reusable workflow, an existing skill may be stale, or a proposed learning may deserve promotion.

## Conventions

- Keep this catalog compact; detailed procedures belong in skill folders.
- Prefer class-level procedures over skills named after a date, issue, person, or single run.
- Update or consolidate before creating another skill.
- New skills require a clear trigger, a reusable workflow, and validation.
- Archive or remove stale skills only after preserving still-useful guidance.
